# Reports — `generated/reports/`

Local **untracked** outputs such as requested development summaries, QA and security review reports, CI diagnostics, dependency audit notes, screenshots or export files.

Write reports here only when requested or required by an explicit workflow. State what was actually verified, with commands and results; never pretend tests or production deployment were performed.

**Git policy:** only this README is tracked. Temporary reports and all new nested directories stay ignored automatically. Long-lived Product documentation belongs in `project/docs/` instead.
