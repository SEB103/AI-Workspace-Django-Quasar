# Tickets — `generated/tickets/`

Local **untracked** Claude Code task records. `/ticket-start` creates `generated/tickets/<task-id>/README.md` for requirements, acceptance checks and links to actual GitHub Issues/PRs; `/ticket-finish` records changes, test evidence and remaining risks.

Task directories are *not* committed to Workspace Git. This README is the only tracked file in `generated/tickets/`. Do not invent GitHub issue numbers; do not store personal data or credentials.

The product's lasting development history belongs to its own GitHub Issues, Pull Requests, commits and tracked product documentation.
