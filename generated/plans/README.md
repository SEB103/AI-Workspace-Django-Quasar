# Plans — `generated/plans/`

Local **untracked** implementation plans and technical proposals created during development. Example: `generated/plans/2026-10-10-patient-booking-plan.md`.

A plan should state goals, assumptions, affected Django/DRF/Wagtail and Quasar components, API contract implications, migrations, tests, risks and acceptance criteria. It is an AI working artifact, not a product specification.

**Git policy:** only this README is tracked. All plans and subfolders are ignored by Workspace Git. Approved lasting architecture decisions belong in `project/docs/adr/` or Workspace tooling decisions in `docs/`.
